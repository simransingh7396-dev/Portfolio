# Personal Portfolio Website

**A responsive digital portfolio acting as a central hub for my academic and technical projects.**

This project was engineered to provide a professional overview of my work as a Computational Mathematics student. It features a clean, minimal design focused on readability, performance, and accessibility across all devices.

###  Technical Highlights
* **Responsive Design:** Utilized CSS Media Queries to ensure a seamless experience on mobile, tablet, and desktop screens.
* **Interactive UI:** Implemented vanilla JavaScript for a dynamic navigation bar (hamburger menu), smooth scrolling, and form validation.
* **Performance Focused:** Optimized code structure and asset loading to achieve high Lighthouse performance scores.
* **Semantic HTML:** Built with accessibility (a11y) best practices in mind, ensuring screen-reader compatibility.
